# Portafolio Junior — Daniel Jiménez

Portafolio web personal desarrollado como proyecto práctico para el programa de Formación en Análisis y Desarrollo de Software (ADSO) en SENA. Construido desde cero aplicando buenas prácticas de maquetación web, control de versiones e integración continua con Git y GitHub.

## 🔗 Demo
https://github.com/dc3861037-byte

## 🛠️ Tecnologías
- HTML5 semántico
- CSS3
- Git y GitHub

## 🌿 Flujo de ramas
- `main`: versión publicada en producción
- `dev`: rama principal de integración
- `feat-ciclo-01` a `feat-ciclo-06`: desarrollo modular por ciclos y secciones

## 📸 Evidencias
1. **Conflicto de fusión en estilos CSS:**
   - *Problema:* Al integrar cambios entre ramas quedaron etiquetas residuales de conflicto (`>>>>>>> Stashed changes`) dentro del archivo `styles.css`[cite: 9], generando errores de sintaxis.
   - *Solución:* Se identificaron las líneas en conflicto[cite: 9], se eliminaron las marcas del *stash/merge*[cite: 9] y se reestructuraron los bloques de reglas CSS para dejar el código limpio.
